## 步骤 1：实体 `Bookmark`

**要写什么**：包名 `org.example.springdemo.entity`，一个普通 POJO，对应表 `bookmark`。

表结构（`db/bookmark-schema.sql` 里）：

```sql
CREATE TABLE bookmark (
    id    BIGINT       NOT NULL AUTO_INCREMENT,
    title VARCHAR(50)  NOT NULL,
    url   VARCHAR(200),
    PRIMARY KEY (id)
);
```

**你自己要想清楚的 4 个问题**：

1. 类名 `Bookmark` 和表名 `bookmark` 对得上吗？需要加注解吗？
   （去看 `SysUser` —— 它为什么要加 `@TableName("sys_user")`？你的情况需要吗？）
2. `id` 是数据库自增的，注解该怎么写？去 `SysUser` 里找答案。
3. 需要无参构造 + getter/setter 吗？为什么不能像 `UserController.User` 那样用 record？
4. 表里三个列 `id / title / url`，对应三个属性，属性名要不要改？（`title`、`url` 本来就是单词，和 `user_name` 那种带下划线的不一样）

## 步骤 4：Controller 的 GET（分页）—— 分水岭

**要写什么**：包名 `org.example.springdemo.controller`，一个 `@RestController`。

**目标接口**：

```
GET /api/bookmarks?current=1&size=5
请求头：token: 123456
预期返回：
{
  "records": [ {12 条中的前 5 条} ],
  "total": 12,
  "current": 1,
  "size": 5,
  "pages": 3
}
```

**你自己要想清楚的 4 个问题**：

1. 类上加什么注解指定路径前缀？（目标是 `/api/bookmarks`）
2. 方法上加什么注解？`current` / `size` 这两个参数从 URL 上来，用什么注解绑定？
   前端不传这两个参数时会怎样？能不能给默认值？
3. 分页对象怎么创建？（去看 `SysUserServiceImpl.pageUsers` 里 `new Page<>(...)` 那一行）
4. 返回值：`IPage` 直接返回行不行？为什么任务卡要求摊平成 `records/total/pages` 这五个字段？
   （去看 `DbQueryController.toPageResult` —— 这题允许你直接参考它，因为它是「格式化」不是「核心逻辑」）

**✅ 做完的标志（这一步必须跑命令，不许目测）**：

```powershell
# 1) 编译
.\mvnw.cmd -q -DskipTests compile

# 2) 重启服务后调接口（devtools 会自动重启，等 5 秒）
curl.exe -H "token: 123456" "http://localhost:8081/api/bookmarks?current=1&size=5"
```

**🔑 关键验证（这是本次练习的核心）**：
去 Spring Boot 控制台，找到这次请求打印的 SQL，**确认里面出现了 `LIMIT`**。

你应该看到类似这样两条：

```
==>  Preparing: SELECT COUNT(*) AS total FROM bookmark
==>  Preparing: SELECT id,title,url FROM bookmark LIMIT ?
```

**如果只看到一条 SELECT、没有 LIMIT，而且返回了全部 12 条** ——
说明分页没生效。别急着问我，先自己回答：**分页是谁负责拼 LIMIT 的？**（看图第 ⑧ 环）

**❓其他常见卡点**：

| 现象 | 你自己去图里找答案 |
|---|---|
| 404 | 第 ③ 环：路径对不对？`/api/bookmarks` vs `/bookmark` |
| 401 | 第 ② 环：token 头带了吗 |
| 500 + `Table "BOOKMARK" not found` | 表名大小写？H2 配置了 `DATABASE_TO_LOWER=TRUE`，你的 `@TableName` 写的什么 |
| 500 + `Unknown column 'xxx'` | 实体属性名和列名对不上 |

## 步骤 5：Controller 的 POST（新增）—— 要返回 201

**目标接口**：

```
POST /api/bookmarks
请求头：token: 123456
请求体：{"title":"我的收藏","url":"https://example.com"}
预期：HTTP 201，且响应里带服务端生成的 id
```

**你自己要想清楚的 3 个问题**：

1. 请求体是 JSON，方法参数用什么注解接收？
   （提示：`UserController.helloJson` 用过；但注意那个用的是 record + `@RequestBody`，
   **这里接收请求体的对象要不要用 record？** —— 想想为什么 `UserDeptVO` 和实体不能用 record，
   而请求体可以）
2. 怎么让 Spring 返回 **201** 而不是 200？（`UserController.create` 里有答案）
3. 新增成功后，前端怎么知道新记录的地址？能不能在响应头里给出？
   （看 `UserController.create` 里 `ResponseEntity.created(...)` 那行）

**✅ 做完的标志**：

```powershell
# 把 JSON 写进文件再传，避免 PowerShell 引号转义问题
'{"title":"我的收藏","url":"https://example.com"}' | Set-Content -Path "$env:TEMP/bm.json" -Encoding utf8 -NoNewline
curl.exe -i -X POST -H "token: 123456" -H "Content-Type: application/json" --data-binary "@$env:TEMP/bm.json" "http://localhost:8081/api/bookmarks"

# 再查一次列表，确认变成 13 条
curl.exe -H "token: 123456" "http://localhost:8081/api/bookmarks?current=1&size=20"
```

**检查点**：状态码是 **201** 吗？`total` 从 12 变成 **13** 了吗？
